# Netflix UI Clone 

A Netflix-inspired webpage built using HTML and CSS for frontend development practice.

## About the Project

This project is a UI clone inspired by Netflix. I created it to practice HTML and CSS, improve my webpage structuring skills, and understand how to recreate a familiar streaming platform interface.

## Features

* Netflix-inspired user interface
* Movie and show presentation sections
* Custom webpage layout and styling
* HTML-based page structure
* CSS-based visual design

## Technologies Used

* HTML5
* CSS3

## What I Learned

* Structuring webpages using HTML.
* Styling layouts and elements using CSS.
* Working with images, spacing, and alignment.
* Practicing frontend UI recreation.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Completed practice project.
